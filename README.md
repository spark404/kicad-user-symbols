# KiCad User Symbol Library

Custom KiCad schematic symbol library (`Custom_Components`) for personal projects.

## Installation

Copy `sym-lib-table` to your KiCad user config directory, or add the library manually in KiCad via **Preferences → Manage Symbol Libraries**:

| Field | Value |
|-------|-------|
| Name  | `Custom_Components` |
| Type  | KiCad |
| URI   | `${KICAD_USER_SYMBOL_DIR}/Custom_Components.kicad_symdir` |
