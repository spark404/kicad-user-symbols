# KiCad User Symbol Libraries

Custom schematic symbols for personal projects, one `.kicad_sym` per part, grouped in `.kicad_symdir` libraries that mirror the footprint libraries in `../user-footprints`.

## Installation

Add `sym-lib-table` as a nested table in KiCad (**Preferences → Manage Symbol Libraries**, type `Table`), or add each library manually using the URIs in `sym-lib-table` (`${KICAD_USER_SYMBOL_DIR}/<name>.kicad_symdir`).
